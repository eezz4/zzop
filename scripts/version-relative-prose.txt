# Registry for scripts/check-version-relative-prose.sh. Three line kinds, whitespace-separated.
#
#   VETTED <version>
#     The workspace version the `claim` lines below were last READ against. When Cargo.toml's version
#     moves, every claim reds until a human re-reads those sentences and bumps this line. Bumping it
#     without re-reading is the one way to defeat this guard, and it is a deliberate act with a diff.
#
#   claim <path> <line-count>
#     <path> makes <line-count> version-boundary claims — sentences naming an explicit vX.Y.Z edge
#     ("from v0.30.0 onward", "up to and including v0.29.1"). The count is registered so that ADDING a
#     claim to an already-vetted file also reds; a file whose claims all disappear reds too, because a
#     registry entry that vouches for prose that is gone is worse than no entry.
#
#   exempt <path> <reason>
#     <path> may use an unanchored deictic ("the current release", "the next release"). The reason is
#     mandatory and is read by the next person, not by the machine. Liveness-checked: if the deictic is
#     gone, the exemption reds — an exemption cannot outlive what it excuses.

# Considered and DECLINED on 2026-08-14: per-claim evidence (a line number or a quoted needle on each
# `claim` line), so that one blanket `VETTED` bump would split into N acts each needing the file open.
#   - Line numbers are not evidence: any insertion above a claim shifts it, so the column would red on
#     edits that never touched the sentence, and a guard that reds on unrelated work gets muted.
#   - A quoted needle reds on every rewrap of a hard-wrapped paragraph. Both files carrying multiple
#     claims are wrapped at ~100 columns and rewrap routinely, so the same muting pressure applies.
#   - A hash of the matched lines survives both objections but does NOT buy the thing wanted: it still
#     leaves ONE `VETTED` line to bump, so it detects a changed claim, never a careless re-read.
# Splitting the re-read into N acts needs per-claim VETTED versions, i.e. a different guard shape, and

# all four claims it vouched for were re-read on 2026-08-14 and were true. The defect that motivated
