개인정보 처리방침

zzop 은 아무것도 수집하지 않는다. 짧게 말하면: 당신의 코드는 당신의 기기를 떠나지 않고, 당신이나 당신의 사용에 관한 어떤 데이터도 zzop 이 모으거나 전송하거나 저장하지 않는다.

zzop 이 당신의 데이터로 하는 일

  • 분석은 전부 로컬이다. zzop CLI, zzop-mcp MCP 서버, npm 패키지 전부 당신의 기기에서만 돌고, 당신이 가리킨 레포지토리 경로만 읽는다.
  • 네트워크 접근이 없다. 분석 바이너리는 어떤 종류의 네트워크 요청도 하지 않는다 — 설계가 그렇고, HTTP 의존성이 0개다. 소스와 의존성 트리에서 확인할 수 있다.
  • 텔레메트리가 없다. 사용 추적도, 크래시 리포팅도, 애널리틱스도 없고, 당신이나 당신의 코드에 관한 것은 어디로도 안 나간다 — 바이너리도, MCP 서버도, Claude Code 플러그인도. 플러그인 자신의 네트워크 활동은 그 문장에 안 덮이며, 묻어 두는 대신 여기서 센다: SessionStart 훅이 api.github.com 에 최신 릴리스 태그를 묻는다 — 세션마다 한 번 — 새 버전이 있다는 것을 보고하기 위해서다(보고만 하고 절대 적용하지 않는다). 설치 첫 회에는 같은 훅이 GitHub Releases 에서 서버 바이너리와 SHA256SUMS 를 받는다 — 요청 두 번 더, 설치 시점에만, 아래 설치 절이 다루는 것과 같은 접촉이다. 그리고 플러그인의 /zzop:update 슬래시 커맨드는 당신이 실행할 때마다 최신 릴리스 요청을 한 번 반복한다. 세션마다 반복되는 그 요청은 당신의 IP 를 실어 나르고 세션이 시작됐다는 사실을 드러낸다. 그 외에는 아무것도 싣지 않는다. 분석 바이너리 자체는 네트워크 요청을 전혀 하지 않는다.
  • 계정도 키도 없다. zzop 은 가입도, API 키도, 자격증명도 요구하지 않는다.
  • MCP 통신은 로컬에 머문다. MCP 서버는 당신의 기기에서 당신의 MCP 클라이언트(예: Claude Code / Claude Desktop)와 stdio 로 JSON-RPC 를 주고받는다. 그 클라이언트가 분석 결과를 가지고 무엇을 하는지는 이 방침이 아니라 그 클라이언트의 방침이 정한다.

설치하면서 닿을 수 있는 외부 서비스

릴리스 바이너리나 npm 패키지를 받는 일에는 GitHub 과 npm 의 인프라가 관여하고, 그것은 각자의 방침이 정한다:

  • GitHub (릴리스, 레포지토리): GitHub privacy policies
  • npm (패키지 레지스트리): npm privacy policy

변경

zzop 의 동작이 이 방침에 영향을 주는 방식으로 바뀌면, 이 페이지는 같은 커밋에서 함께 바뀐다 — 공개 레포지토리 이력에 남는다.
